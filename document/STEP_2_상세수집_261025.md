# STEP 2 상세 수집 — 결정 및 핵심 내용

작성일: 2026-10-25 · 상위 문서: [STEP_0_구현설계서_261025.md](STEP_0_구현설계서_261025.md) · 관련: [STEP_1-2_엔티티병합_261025.md](STEP_1-2_엔티티병합_261025.md)

STEP 2(업체 상세 정보 수집)에서 "업체 판정·증거 등급·문서 수집이 실제로 어떻게 생성되는가"를 못 박은 기록입니다. 데모 `html/second-chair-sourcing-demo.html`의 STEP 2 화면과 `SUP` 데이터가 전제한 내용의 근거입니다.

## 멀티모달 전제 (결정)

- **멀티모달 LLM 가용을 가정**하고 설계. 인증서 PDF/이미지에서 인증번호·유효기간을 LLM이 직접 판독하고, 설비 사진은 보조 증거로 사용.
- 경로와 무관하게 **추출값엔 원본 문서 Evidence를 반드시 첨부**(설계 원칙 1).
- **리스크(1주차 확인):** 사내 승인 LLM이 텍스트 전용으로 확정되면 인증서 판독 경로가 막힘 → OCR+텍스트LLM 폴백으로 전환 필요. 설계가 멀티모달 가정에 걸려 있음을 명시.

## 증거 등급 rubric (L1/L2/L3)

LLM은 "이 문장/이미지가 어떤 증거 유형인가"만 분류하고, 유형→등급 매핑은 **결정적 규칙 테이블**이 부여한다(설계 원칙 2 — 재현성 확보).

| 등급 | 판정 근거 (증거 유형) | 데모 예시 |
| --- | --- | --- |
| **L1** | 웹페이지 텍스트 언급만 (사양·사진·문서 없음) | 청우코텍 "하드코팅 언급 1회" |
| **L2** | 설비 사양/사진, 또는 제품 사양표 | 서진코팅 "AF 라인 사진, 접촉각 110°" |
| **L3** | 특허·인증서·시험성적서·납품실적 중 1개 이상 | 서진코팅 "하드코팅 조성물 특허 3건" |

→ 같은 입력이면 항상 같은 등급. LLM 자의 판정 배제.

## 크롤링 페이지 분류·예산 배분

사이트맵을 읽어 페이지를 유형 분류하고, 소싱 스펙 역량 증거에 기여하는 순으로 업체당 약 30쪽 예산을 할당.

1. 설비/공정 페이지 (`/equipment`, `/facility`) — L2 증거 핵심
2. 인증 페이지 (`/certification`) — L3 증거 + 인증번호
3. 제품 페이지 (`/products`) — 사양표
4. 회사소개/연혁 — 사업자 정보·공장 주소 (→ 2차 흡착 재료)
5. 고객사/납품실적 — L3 증거
6. 그 외(채용·뉴스 등) — 예산 남을 때만

→ 상위 유형부터 할당. 영세 업체는 예산을 다 못 쓰고 "정보 부족" 태그로 귀결(데모의 페이지 수 편차를 설명).

## 2차 흡착 (엔티티 해석 2차 라운드)

STEP 2 크롤링의 부산물로 엔티티 병합 2차 라운드가 발생([STEP_1-2_엔티티병합_261025.md](STEP_1-2_엔티티병합_261025.md) "흡착은 2회 발생"):

- 회사소개 페이지에서 사업자등록번호·공장 주소가 드러남 → 앵커(팩토리온)에 재대조 → 미흡착이던 순수 웹 후보가 사업자번호 상속.
- 여전히 미흡착 → "사업자번호 미확보·현장 확인 필요" 태그 확정.

→ STEP 2는 "상세 수집"이자 엔티티 해석 2차 라운드를 겸함.
