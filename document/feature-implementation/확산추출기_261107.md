## 요약

앵커(팩토리온)가 "검증"이라면, 확산 추출기는 "발견(discovery)"이다. 공개 B2B
디렉터리에서 공급사 후보(회사명·URL·국가·생산품)를 넓게 긁어, 앵커에 흡착해 검증한다.
비용순 레지스트리의 2·4계층을 구현했다(2계층 웹검색은 앞서 완료).

| 계층 | 추출기 | 대상 | 비용 |
| --- | --- | --- | --- |
| 2 | ConfigDriven (YAML 셀렉터) | 비슷한 구조의 디렉터리(EC21·고비즈코리아) | 싸다 |
| 2 | WebSearch (SerpApi) | 다국어 구글 검색 | 싸다(앞서 완료) |
| 4 | LlmFallback (LLM 파싱) | 설정·코드 없는 임의 사이트(중국 등) | 비싸다 |

모든 확산 레코드는 `source_class=SPREAD`·`verified=False` — **앵커 흡착 전까지 미검증**.

## 1. 2계층 — 선언형 설정 (`config_driven.py`)

비슷하게 생긴 디렉터리는 CSS 셀렉터를 YAML로 기술한다. **신규 사이트 편입 = 코드가
아니라 `config/*.yaml` 한 장 추가** → import 시 자동 등록(`load_configs` glob).

- 한 YAML = 한 소스: `source_id`·`source_class`·`search_url`(`{q}`·`{hl}` 치환)·
  `item_selector`(업체 블록)·`fields`(각 필드 `selector`+`attr`).
- `_parse`가 라이브·픽스처 공용: Fetcher가 HTML을 주면 BeautifulSoup+lxml로 파싱.
- URL 정규화: 상대경로(`/global/…`)·프로토콜상대(`//…`)를 절대 URL로. 비URL은 `None`.
- 회사명 없는 블록(광고·배너)은 건너뜀.
- Fetcher 공유 → 캐시·레이트리밋·robots·골든 픽스처 주입 그대로 사용.

등록 YAML: `ec21.yaml`(글로벌), `gobizkorea.yaml`(KOTRA 국내 수출 디렉터리).

> **셀렉터는 라이브 전 조정 전제.** 실사이트 구조 확인 시 YAML만 고치면 되고 코드는
> 불변. 픽스처(`data/fixtures/config_driven/ec21_hardcoating.html`)로 로직을 고정.

### 존 분리

`search_url`에 내부 품목코드·단가·현 협력사명을 넣지 않는다(공정·소재 키워드만).

## 2. 4계층 — LLM 폴백 (`llm_extract.py`)

전용 추출기도 YAML 셀렉터도 없는 사이트를 커버한다. 정리한 HTML + 목표 스키마를
LLM(`src/llm/complete_json` 재사용)에 주고 공급사 레코드를 뽑는다. **구조가 바뀌어도
견디고, 설정·코드 없는 신규 사이트를 즉시 커버 — "pool 자생 확장"의 열쇠.**

- 가장 비싼 계층이라 `tier=4`(레지스트리 맨 뒤, 최종 폴백).
- `_clean`: script·style·head·svg 제거, 앵커 텍스트 옆에 `<url>` 임베드, 빈 줄 접기,
  `MAX_CHARS=12000`로 절단 → 토큰 절약.
- 구조화 출력 스키마: 회사명·홈페이지·국가·지역·생산품·`is_manufacturer`·스니펫.
  **LLM이 제조사/무역상까지 판정**(무역상·소싱에이전트·유통사 = false).
- `query={'url'}`이면 Fetcher로 라이브, `{'html'}`이면 직접 파싱(픽스처).
- URL 정규화·`verified=False`는 2계층과 동일.

### 글로벌(중국) 시연 안정화

안티봇이 강한 글로벌 디렉터리는 라이브 중 막히면 데모가 깨진다. → **저장 스냅샷에서
실제 추출 로직을 돌린다**(추출은 진짜, 네트워크 불확실성만 제거).
픽스처: `data/fixtures/llm_extract/made_in_china_coating.html`(중문 모사).

## 3. 검증

- **라이브 OpenAI 호출**(중문 픽스처): 제조사 2곳(Suzhou BrightFilm·Dongguan
  CoatingTech) → `manufacturer`+생산품 추출, 무역상(Global Trade HK) → `trader`로
  정확히 하향. 모두 `verified=False`·홈페이지 URL 정규화.
- 오프라인 결정적 테스트:
  - `tests/test_config_driven.py` 5종 — YAML 로드, 블록 파싱, SPREAD·미검증,
    상대/프로토콜 URL 절대화, 국가·스니펫 추출.
  - `tests/test_llm_extract.py` 5종 — tier4 등록, `_clean`(스크립트 제거·링크 임베드·
    절단), `_safe_url`(정규화·쓰레기 거부). **LLM 호출 자체는 비결정적·유료라 제외.**
- 전체 스위트 26 passed (registry 3 + factorion 5 + web_search 4 + llm_logic 4 +
  config_driven 5 + llm_extract 5).
- 레지스트리 최종: tier1 factorion(anchor) / tier2 ec21·gobizkorea·web_search / tier4 llm_extract.
