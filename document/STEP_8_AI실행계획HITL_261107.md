## 배경

접수 단계 제거 후, 발견·검증의 첫 단계인 **STEP 0 소싱 스펙 정의**가 사실상 소싱의
출발점이 되었습니다. 기존에는 담당자가 "스펙 생성 → 검토 → 스펙 확정 및 탐색 실행"으로
**한 단계씩** 수동 진행했습니다.

여기에 "사용자가 요청하면 AI가 요청을 분석해 이후 단계를 진행"하자는 아이디어가 나왔습니다.
단, 전체 설계 4원칙 중 **"사람 확인 지점(자동 조치는 제안→승인, 자동 전진 금지)"** 과
충돌할 수 있어, **완전 자동이 아닌 HITL(Human-in-the-loop) 절충안**으로 반영했습니다.

## 설계 — "화면 전환은 사람, 각 단계 실행은 AI"

STEP 0에서 스펙을 생성하면, AI가 **스펙 초안 + 이후 단계 실행 계획**을 함께 제안합니다.
사람이 승인하면 **자동 모드**가 켜지되, **화면을 넘기는 행위는 사람이 직접** 합니다
(각 화면의 [다음] 버튼). 사람이 다음 화면에 도착하면 **그 단계의 탐색·수집을 AI가
자동으로 실행**합니다.

> **설계 변경 이력:** 최초안은 승인 시 화면까지 자동으로 전환했으나, "AI가 화면을
> 알아서 넘기는 것은 어색하다"는 피드백으로 **화면 전환을 사람의 [다음] 클릭으로**
> 되돌렸습니다. 자동화는 "각 단계 실행"에만 적용됩니다.

### 핵심 결정 — 자동 실행 범위

자동 실행은 **발견·검증 구간(탐색→상세→숏리스트)까지만** 적용하고 **숏리스트에서 종료**됩니다.

- 되돌릴 수 있는 **조회·수집 구간만** 자동 실행합니다.
- 화면 전환(단계 이동)은 **항상 사람**이 합니다.
- 그 다음(RFI 외부 발송, 협상 분석)은 **되돌릴 수 없거나 외부로 나가는** 행위이므로
  반드시 사람의 별도 승인을 받습니다. → "사람 확인 지점" 원칙 준수.

### HITL 배지

STEP 0 crumb와 AI 실행 계획 카드에 **`HITL`** 배지(파란 chip)를 노출해, 이 자동화가
사람 승인을 전제로 함을 시각적으로 명시합니다.

  - **다음 단계: 후보 업체 탐색 ▸**(ghost, `data-go="long"`) — 사람이 다음 화면으로 이동

### JS

- `btnDecompose` 핸들러 끝에 **실행 계획 수립** 로그·단계 목록 렌더링 추가
  (필수/우대 개수를 스펙에서 집계해 표시)
- STEP 1·2 실행 로직을 **await 가능한 함수로 추출**: `runLong()` / `runDeep()`.
  기존 버튼 핸들러는 이 함수를 호출하는 얇은 래퍼로 변경(동작 동일).
- **`btnAutoRun` 핸들러**: `autoMode` 플래그만 토글. 화면 전환은 하지 않음.
- **`autoRunOnEnter(id)`**: `go()` 말미에서 호출. 자동 모드이고 해당 단계가 `AUTO_RUN`에
  있으면(long/deep) 그 실행 함수를 **단계당 1회**(`autoDone` Set) 자동 구동. `short` 도달 시
  `autoMode`를 꺼서 자동 실행을 종료(HITL 정지점).

### 보존 (회귀 방지)

- STEP 1·2 버튼 수동 클릭 동작은 리팩터링 후에도 동일.
- 화면 전환은 전 구간에서 사람이 수행(자동 전환 없음).
- `go()`에 추가한 `autoRunOnEnter`는 자동 모드가 아닐 때 즉시 반환 → 기존 흐름 무영향.
- 다른 화면·네비게이션·`computeShort`·INIT 1회성 패턴 등 무변경.

## 검증

- JS 파싱: `node vm` 통과 (`parse ok`)
- 참조하는 id·함수 전수 존재 확인 (btnAutoRun·autoNote·runLong·runDeep 등)
- `computeShort`는 모듈 상수 POP 기반이라 deep 완료와 무관하게 동작 → 데이터 공백 없음
- 자동 실행 중 개별 실행 버튼은 `disabled` 처리, `autoDone` Set으로 단계당 1회 보장

## 트레이드오프 / 남은 판단

- **데모는 시뮬레이션**입니다. 실제 LLM 분석·계획 수립이 아니라, 사전 정의된 스펙·단계를
  순차 애니메이션으로 연출합니다. 실제 기능 구현(요청 분석·계획 생성의 LLM 연결)은 별도 과제.
- 자동 실행 범위(숏리스트까지)는 조정 가능 — 더 짧게(STEP 1까지) 혹은 더 길게(RFI 직전)로
  바꿀 수 있으나, 현재는 "외부로 나가기 직전"을 경계로 삼았습니다.
