# 접수 — 소싱 요청 창구

작성일: 2026-11-01
상위 문서: [STEP_6_업무확장설계_261101.md](STEP_6_업무확장설계_261101.md)

## 문제

기존 데모는 **구매현황 자동 진단**(원자재 미연동·단일소싱 등으로 재협상 대상 품목을 에이전트가 제시)만 소싱 트리거로 가정했습니다. 그러나 현장에서는:

- 담당자가 **선행연구·신규 제품 출시**에 따라 개별적·자율적으로 소싱을 요청해야 하는 경우가 많습니다.
- 삼성디스플레이 내부 업무는 **IPC(소싱 담당자)가 소싱 후 RFP를 발송 → 업체 회신 → 검토 → 소싱 요청자에게 전달**하는 흐름입니다. 즉 "요청자"와 "소싱 담당(IPC)"이 분리되어 있습니다.

## 결정 1 — 트리거 이원화

소싱 파이프라인의 입구를 두 갈래로 둡니다. **두 경로 모두 동일한 SourcingRequest로 합류**해 이후 단계(스펙→롱리스트→…)는 공통입니다.

| 경로 | 주체 | 설명 |
| --- | --- | --- |
| 자동 진단형(기존) | 에이전트 제안 | 구매현황 분석으로 재협상/다변화 대상 품목 제시 |
| 수동 요청형(신설) | 요청자(수요부서) | 선행연구·신제품 목적의 자율 소싱 요청 작성 |

자동 진단형은 "에이전트가 먼저 제안" → IPC가 채택, 수동 요청형은 "요청자가 올림" → IPC가 접수. 접수 이후의 책임 주체는 IPC로 통일됩니다.

## 결정 2 — 요청 폼 필드

수동 요청형 폼은 다음을 받습니다. **산업군/기술만이 아니라 품목·자재코드 수준까지** 지정 가능하게 합니다(피드백 반영).

| 필드 | 필수 | 비고 |
| --- | --- | --- |
| 요청 목적 | ✓ | 선행연구 / 신제품 / 다변화 / 단종 대응 등 |
| 산업군·기술 | | 1차 범위 좁히기 |
| 품목 검색 | | 품목명 자유어 검색 → 자재 마스터 후보 제시 |
| 자재코드 지정 | | 코드 검색·선택. 지정 시 과거 사양·현 협력사·단가 이력 자동 연결 |
| 사양 요약 | ✓ | 자재코드 지정 시 자동 프리필, 수정 가능 |
| 희망 일정 | | 소싱 완료 목표일 |

**자재코드를 지정하면** 요청자가 사양을 처음부터 쓰지 않아도 되고, IPC는 "현 협력사가 누구이고 지금 단가가 얼마인지"를 요청 시점에 바로 봅니다.

## 결정 3 — 유사 자재 추천

자재코드를 모르거나, 신규 자재라 기준이 없을 때를 위해 추천을 제공합니다.

- **방식:** 자재 마스터(MaterialRef)의 품목명·사양 텍스트를 임베딩(기존 기술스택 pgvector)해, 요청자가 입력한 품목명/사양과 **유사 자재 top-N**을 제시.
- **용도:** ① 요청자가 유사 자재의 사양을 출발점으로 삼아 스펙 작성 부담을 줄임 ② "이 자재와 유사한 기존 자재가 이미 있다" → 중복 소싱 방지.
- **표시:** 추천 자재마다 코드·현 협력사·단가 이력 요약을 함께 보여주고, "이 사양 가져오기" 액션 제공.

## 결정 4 — 역할과 상태

STEP_6 역할 전환 개념을 접수 단계에 적용합니다.

```
요청자: 요청 작성 → 제출
IPC:    접수함에서 확인 → 접수(채택) → 스펙 정의(STEP 0)로 전진 / 반려(사유 기재)
```

| 상태 | 의미 | 다음 |
| --- | --- | --- |
| 작성중 | 요청자 초안 | 제출 |
| 제출됨 | IPC 접수 대기 | 접수 / 반려 |
| 접수됨 | IPC가 채택, 소싱 착수 | STEP 0 스펙 정의 |
| 반려됨 | 사유와 함께 요청자에게 회신 | (요청자 재작성) |

## 에이전트/코드 분업

- **에이전트:** 품목명 자유어 → 자재 후보 매칭, 유사 자재 추천 근거 서술, 사양 요약 프리필.
- **코드:** 자재코드 정합성 검사, 단가 이력 조인, 상태 전이 규칙, 임베딩 유사도 계산.

## 데모 반영 범위

- **실제 동작:** 수동 요청 폼 + 자재코드 검색(mock 자재 마스터) + 유사 자재 추천 + 접수함(요청자/IPC 역할 전환).
- **자리만 확보:** 임베딩 실연결(데모는 사전 계산된 유사도 사용), 반려 재작성 루프.
