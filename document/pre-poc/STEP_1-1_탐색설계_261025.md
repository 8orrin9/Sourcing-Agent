# STEP 1 탐색 설계 — 결정 및 핵심 내용

작성일: 2026-10-25 · 상위 문서: [STEP_0_구현설계서_261025.md](STEP_0_구현설계서_261025.md)

STEP 1(후보 업체 탐색)의 "어디서/어떻게 찾는가"를 못 박은 결정 기록입니다. 데모 `html/second-chair-sourcing-demo.html`의 STEP 1 화면이 전제한 내용의 실제 근거를 정리합니다.

## PoC 스코프

- **실행 범위: 국내 제조사 우선.** 다국어·해외 소스는 설계 자산으로 등록해 2차 확장에 대비합니다.
- "구조는 다국어(KR·EN·ZH·VI)까지 완성, PoC는 국내에 집중" — 데모에 뜬 중국·베트남 후보는 확장성 메시지 용도.

## 소스 레지스트리

소스를 **검증 키를 가진 앵커**와 **재현율을 넓히는 확산**으로 구분합니다. 엔티티 병합은 앵커를 기준점으로 확산 소스를 끌어 붙입니다.

| 소스 | 유형 | 접근 방식 | 얻는 필드 | PoC 상태 |
| --- | --- | --- | --- | --- |
| 웹 검색 | 확산 | LLM 검색 API(Tavily류) + 범용 검색 API 병행 | 회사명, URL, 스니펫 | 국내(KR·EN) 적용, ZH·VI·Baidu는 준비만 |
| B2B 디렉터리 | 확산 | KOTRA 소재부품종합정보망·중기부 자료(공개), EC21·국내 B2B(크롤, ToS 확인) | 회사명, 취급품목, 연락 URL | 국내 적용, 해외는 비검증 참고 |
| 공장등록(팩토리온) | **앵커** | 한국산업단지공단 공개 데이터 | 법인명, 주소, 업종·생산품목(가능 시 사업자번호) | 제조사 판정 1차 근거 |
| 특허 출원인(KIPRIS) | **준앵커** | 한국특허정보원 오픈 API | 출원인명·출원인코드·주소, 기술 분류 | 역량 증거 + 공장등록 교차 매핑 |
| 전시회 참가사 | 확산 | exhibitor 디렉터리 수동 시드(K-Display·나노코리아 등) | 회사명, 전시 분야 | 1회성 수동 적재 |
| 협회 회원사 | 확산 | 협회 명부(공개) | 회사명, 소재지 | 보조 |

### 소스별 결정

- **웹 검색:** Tavily류 1개 + 범용 1개 병행(두 엔진으로 재현율 확보). 중국은 Baidu 준비만.
- **B2B:** 국내 한정(KOTRA·중기부·EC21·국내 B2B). 해외 디렉터리(Alibaba·Made-in-China)는 ToS 리스크·무역상 노이즈로 비검증 참고 등급.
- **공장등록(팩토리온):** 생산품목까지 주는 거의 유일한 국내 소스 → 제조사 판정의 진짜 앵커. 생산품목·주소·사업자번호 공개 범위는 1주차 확인.
- **전시회:** 자동화 가치 낮음 → 1회성 수동 시드로 소스 다양성만 확보.
- **특허(KIPRIS):** "구글링을 넘는 리서치"를 가장 잘 보여주는 소스. 국내 한정.

### 수집 필드의 비대칭 (설계 함의)

- 웹·B2B·전시회 → **회사명/URL만** (사업자번호 없음) = 확산 소스
- 공장등록·특허 → **사업자번호·주소·생산품목까지** = 앵커 소스
- → 엔티티 병합은 앵커를 기준점으로 확산을 끌어 붙이는 방향. 이름→사업자번호 해소 급소를 국내에서 푸는 경로와 직결.

## 특허 출원인 → 제조사 매핑

KIPRIS는 사업자번호를 주지 않고, 출원인 표기 변형·개인/연구소 명의 문제가 있어 특허를 **준앵커**로 다룹니다.

1. **출원인코드**(KIPO 고유키)로 동일 주체 묶기 — 표기 흔들림 흡수.
2. **법인명 정규화 + 출원인 주소를 팩토리온과 대조** → 제조사 확정(이때 사업자번호 획득).
3. 매칭 실패 → "특허 보유 추정·제조사 확인 필요" 태그(감점 아님).
4. 개인·대학·연구소 단독 출원인 → 후보 제외.

→ **팩토리온이 앵커, 특허는 팩토리온에 조인되는 준앵커.**

## 기존·과거 협력사 표시 (존 분리 준수)

- 외부 탐색은 공개 정보만 사용. 내부 협력사 마스터 대조(기존 거래·과거 탈락)는 **숏리스트가 내부 분석 존으로 넘어온 뒤** 수행.
- 데모의 "기존 협력사/현 협력사" 태그는 내부존 진입 후 입히는 것으로 정리(설계 원칙 3 준수).

## 다국어 쿼리 생성 규칙

LLM 자유 작문이 아니라 **슬롯 조립 문법**으로 생성(설계 원칙 2):

```
[재질] [형태] [공정] [의도앵커] [조건수식어]?
```

| 슬롯 | 출처 | PMMA 케이스 |
| --- | --- | --- |
| 재질 | 소싱 스펙 + 온톨로지 동의어 | PMMA / 아크릴 / acrylic / 亚克力 / nhựa acrylic |
| 형태 | 소싱 스펙 | 시트 / sheet / 片材 / tấm |
| 공정 | 온톨로지 공정 동의어 | 하드코팅 / hard coating / 硬化涂层 / phủ cứng |
| 의도앵커 | 언어별 고정 사전 | 제조·공장 / manufacturer·factory / 工厂·厂家 / nhà máy |
| 조건수식어 | 소싱 스펙 필수조건 | 클린룸 / 내지문 / 연필경도 3H |

### 결정

- **확장 전략: 언어×공정 그리드 + 조건수식어 1단 변형.** (데모의 3공정×4언어 기본축) 핵심 공정에만 수식어 변형 추가 — 재현율과 노이즈·비용의 균형.
- **역할 분리:** 의도앵커 = 쿼리에서 제조사를 **당기는(pull)** 장치 / 무역상 부정어 = 결과에서 **밀어내는(push)** 장치.
- **부정어 위치: 결과 필터 단계.** 쿼리엔 넣지 않음 — 정상 제조사 페이지에 "수입/도매" 어휘가 있어 통째로 날아가는 리콜 손실 방지.
- **언어↔시장:** KR·EN 실행 / ZH(Baidu)·VI 준비. 온톨로지에 ZH·VI 동의어·의도앵커 미리 적재.

### 송출 필터 (원칙 3)

조립된 쿼리를 외부로 보내기 직전 검사 — 품목코드 패턴·단가/수량 숫자·협력사명 blocklist 포함 시 차단하고 **차단 사유를 로그에 기록**(감사 대응).
