# 컨택 — RFI 발송·회신·분석

작성일: 2026-11-01
상위 문서: [STEP_6_업무확장설계_261101.md](STEP_6_업무확장설계_261101.md)

## 문제

숏리스트까지 만들어도 **실제 업체 접촉**에서 막힙니다. 현장 피드백:

- 업체 홈페이지 공개 정보에서 **컨택 포인트를 찾기 어렵고**, 찾아도 RFI 요청에 **무응답이 많습니다.**
- 그래서 에이전트가 **메일 발송 → 회신 수신 → 관리**까지 하는 자동화 프로세스가 필요합니다.
- 구체적으로 **RFx 자동 작성, 회신 내용 자동 분석, 무응답 조치**를 고려해야 합니다.

## 결정 1 — 컨택 포인트 발굴

새 크롤링을 돌리지 않고, **STEP 2 상세 수집 파이프라인에 추출 항목을 추가**합니다(중복 작업 방지).

- **추출 대상:** 대표 이메일, 영업·구매 문의 폼 URL, 담당 부서명. **개인 실명·개인 연락처는 저장하지 않음**(STEP_0 보안 원칙: 개인정보 비저장).
- **등급화:** 컨택 포인트도 증거처럼 출처 URL·수집일을 붙이고, "대표메일 / 문의폼 / 미발견"으로 구분.
- **미발견 시:** 공공 DB(공장등록 등)의 대표 연락처를 폴백으로 제시하되 "미검증" 표시.

## 결정 2 — RFx 자동 작성

확정 스펙(STEP 0)과 숏리스트 근거를 재료로 **RFI 초안을 자동 생성**합니다.

- **구성:** 회사 소개, 요청 품목·공정·인증 요건(온톨로지 용어), 회신 요청 항목(역량·인증서·샘플 가능 여부·리드타임·개략 단가 수준), 회신 마감일.
- **존 분리 준수:** 외부로 나가는 RFI에는 **내부 단가·품목코드·현 협력사명을 넣지 않습니다**(STEP_0 쿼리 정제 원칙과 동일). 요청 항목은 공정·재질 등 일반 용어로만.
- **RFI → RFP 발전:** RFI(정보 요청, 비구속)로 시작해, 회신으로 후보가 좁혀지면 동일 골격을 **RFP(제안 요청)로 승격**. 레퍼런스 SRM의 RFP 흐름과 접속되는 지점.
- **에이전트/코드 분업:** 문면 작성은 에이전트, 수신자 목록·마감일·발송 큐는 코드.

## 결정 3 — 발송·추적 보드

업체별 컨택 상태를 하나의 보드에서 추적합니다.

| 상태 | 의미 | 트리거 |
| --- | --- | --- |
| 초안 | RFI 생성됨, 미발송 | IPC 검토 |
| 발송 | 업체에 전달 | (PoC: 시뮬레이션) |
| 열람 | 업체가 열어봄 | 추적 픽셀/포털 로그 가정 |
| 회신 | 업체 응답 수신 | 첨부·본문 파싱 |
| 무응답 | 마감 경과·미응답 | 자동 판정 |

## 결정 4 — 무응답 자동 조치 (에스컬레이션)

무응답이 많다는 현장 문제에 대한 핵심 장치입니다.

```
발송 후 D+N1: 1차 자동 리마인드
발송 후 D+N2: 2차 리마인드 + 대체 컨택 포인트로 재시도(문의폼 등)
발송 후 D+N3: 무응답 확정 → 후순위 후보를 숏리스트에서 자동 승격 제안
```

- N1/N2/N3 일수는 설정 파일로 구매팀이 조정(STEP_0 하드필터 설정 방식 계승).
- "후순위 승격"은 STEP 3 숏리스트의 예비 후보(60점 이상 미선정)를 당겨오는 것이라 기존 자산과 직결.
- 모든 조치는 **자동 실행이 아니라 제안 → IPC 승인** 후 실행(사람 확인 지점 원칙).

## 결정 5 — 회신 자동 분석 (증거 등급 승급)

회신 문서를 파싱해 **숏리스트 역량표를 갱신**합니다. 이것이 RFI의 가장 큰 값입니다.

- **파싱:** 회신 본문·첨부(회사소개서·인증서·시험성적서)에서 공정 역량·인증·리드타임·샘플 가능 여부를 추출.
- **증거 등급 접속:** 기존 L1~L3 체계와 **검증 등급**(교차검증/서류확인/주장만)에 그대로 연결.
  - 홈페이지 "주장만(미검증)"이던 항목이, 회신으로 **인증서·시험성적서 원본**을 받으면 "서류 확인"으로 **승급**.
  - 승급 이력은 RfxResponse에 로그로 남겨 역추적(증거 우선 원칙).
- **표시:** 숏리스트 역량표에 "회신 전/후" 뱃지 변화를 보여줘, RFI가 판단을 어떻게 개선했는지 가시화.

## 데이터 흐름

```
숏리스트(STEP 3) ─→ 컨택 포인트(STEP 2 추출) ─→ RFx 초안(에이전트)
   │                                                  │
   └───────────────── 후순위 승격 ←── 무응답 확정 ←── 발송·추적 보드
                                                       │
                      증거 등급 승급 ←── 회신 파싱 ←── 회신 수신
```

## 데모 반영 범위

- **실제 동작:** RFI 초안 자동 생성(스펙 기반), 발송·추적 보드(상태 시뮬레이션), 무응답 리마인드/후순위 승격 제안, 회신 파싱 → 역량표 등급 승급 시각화.
- **자리만 확보:** 실제 메일 발송/수신(2차 과제), 열람 추적 실데이터, RFP 전체 폼(레퍼런스 SRM 연계 시 확장).
